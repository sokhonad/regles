# Politique de Confidentialité - PharmaConnect

**Dernière mise à jour : 24 Janvier 2026**

PharmaConnect nous s'engage à protéger votre vie privée. Cette politique de confidentialité explique comment nous collectons, utilisons et protégeons vos informations lorsque vous utilisez notre application mobile.

## 1. Informations que nous collectons

### 1.1 Autorisations de l'appareil
Pour fournir nos services, l'application peut demander l'accès à certaines fonctionnalités de votre appareil :

*   **Caméra (Appareil photo)** :
    *   **Pourquoi ?** Nous utilisons la caméra uniquement pour vous permettre de scanner ou photographier votre ordonnance médicale afin de l'envoyer aux pharmaciens.
    *   **Stockage** : Les photos prises sont envoyées de manière sécurisée sur nos serveurs (Firebase Storage) pour traiter votre demande. Elles ne sont pas partagées avec des tiers non autorisés.

*   **Localisation (GPS)** :
    *   **Pourquoi ?** Nous utilisons votre position pour identifier les pharmacies les plus proches de vous et faciliter la mise en relation.
    *   **Utilisation** : Votre position précise n'est utilisée qu'au moment de la recherche et n'est pas suivie en arrière-plan.

*   **Galerie Photos** :
    *   **Pourquoi ?** Pour vous permettre de choisir une photo d'ordonnance déjà existante sur votre téléphone.

### 1.2 Données personnelles
Lors de votre inscription, nous collectons :
*   Votre nom et prénom (optionnel selon le profil).
*   Votre adresse e-mail (pour l'authentification).
*   Votre numéro de téléphone (pour que le pharmacien puisse vous contacter).

## 2. Comment nous utilisons vos données
Nous utilisons vos données pour :
*   Mettre en relation les patients et les pharmaciens.
*   Vous envoyer des notifications concernant l'état de votre commande.
*   Améliorer la qualité de notre service.

## 3. Partage des données
Vos données (photo d'ordonnance, numéro de téléphone) sont partagées **uniquement** avec les pharmacies inscrites sur la plateforme afin de répondre à vos demandes. Nous ne vendons pas vos données personnelles.

## 4. Sécurité
Nous mettons en œuvre des mesures de sécurité appropriées pour protéger vos données contre tout accès non autorisé (chiffrement, authentification sécurisée via Google Firebase).

## 5. Suppression des données
Vous pouvez demander la suppression de votre compte et de toutes vos données en nous contactant à l'adresse suivante ou via l'option "Supprimer mon compte" dans l'application.
De plus, les ordonnances et demandes sont automatiquement supprimées de nos serveurs après 7 jours.
